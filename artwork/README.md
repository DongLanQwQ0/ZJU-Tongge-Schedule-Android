# 同格 · 原创应用图标

两张错位的课表分别使用薄荷青与鸢尾蓝，浅色交集强调课表重合；一条暖金色共同课程贯穿两侧，将“找到课搭子、一起同行”转化为简单的几何连接。深海蓝底色保证小尺寸下的轮廓辨识度。图标无文字、校徽或第三方品牌素材，由基础几何路径独立绘制，未参照现有商标。

Android 自适应图标使用独立背景与前景。108dp 前景中的实绘范围为 x=25–83、y=26–82，完全位于中心 66dp 安全区域。独立 drawable 版本包含相同背景，适合应用内显示。

`tongge-original-icon.svg` 与 Android vector 使用相同路径和配色。两张 1024px PNG 分别展示圆角方形与圆形裁切。运行 `pwsh -File artwork/render-icon.ps1` 可从 `drawable/ic_launcher.xml` 重新生成前景、SVG 和预览；生成脚本仅使用 Windows 自带的 System.Drawing。

原创绘制并非商标检索或法律结论。未执行商标数据库相似性检索。
